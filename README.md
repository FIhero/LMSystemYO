# Программа для онлайн обучения YO

## Функционал

### Модели:
- **Пользователи** - кастомная модель с email-авторизацией, телефон, город, аватар
- **Курсы** - название, описание, превью, владелец
- **Уроки** - название, описание, видео-ссылка, привязка к курсу
- **Платежи** - пользователь, дата оплаты, курс/урок, сумма, способ оплаты

### API Эндпоинты:

#### Курсы (`/api/courses/`)
- **GET** - список курсов (с количеством уроков и списком уроков)
- **POST** - создание курса
- **GET /api/courses/1/** - детали курса
- **PUT** - обновление курса  
- **DELETE** - удаление курса

#### Уроки
- **GET /api/lessons/** - список уроков
- **POST /api/lessons/create/** - создание урока
- **GET /api/lessons/1/** - детали урока
- **PUT /api/lessons/1/update/** - обновление урока
- **DELETE /api/lessons/1/delete/** - удаление урока

#### Пользователи
- **PUT /api/users/profile/update/** - редактирование профиля

#### Платежи (`/api/payments/`)
- **GET** - список платежей с фильтрацией:
  - `?paid_course=1` - фильтр по курсу
  - `?paid_lesson=1` - фильтр по уроку  
  - `?payment_method=cash` - фильтр по способу оплаты
  - `?ordering=payment_date` - сортировка по дате

## Оплата курсов
1. `POST /api/payments/buy_course/` - создать сессию оплаты
2. Перейти по полученной ссылке
3. Использовать тестовую карту: `4242 4242 4242 4242`
4. `GET /api/payments/payment_status/?session_id=...` - проверить статус

#### Подписки:
- **POST /api/courses/{id}/subscribe/** - подписаться на курс
- **POST /api/courses/{id}/unsubscribe/** - отписаться от курса

### JWT Авторизация:
- Регистрация: POST /api/users/register/
- Получение токена: POST /api/users/token/
- Все эндпоинты закрыты авторизацией

### Права доступа:
- Создана группа 'moderators' 
- Модераторы могут редактировать любые курсы/уроки, но не могут удалять
- Обычные пользователи работают только со своими объектами

### Валидация контента:
- Автоматическая проверка ссылок - в уроках разрешены только youtube.com

### Система подписок:
- Модель Subscription - отслеживание подписок пользователей

### Пагинация:
- Умное разделение на страницы для курсов и уроков
- Гибкие настройки:
  - **Курсы**: 5 на страницу (макс. 20)
  - **Уроки**: 10 на страницу (макс. 50)

## Асинхронные задачи (Celery)

### Автоматические уведомления
- **Рассылка писем** при обновлении курсов
- **Умная отправка** - только если курс не обновлялся более 4 часов
- **Только подписчикам** - целевая аудитория

### Безопасность и модерация  
- **Автоблокировка неактивных пользователей** - если не заходили > 30 дней
- **Периодическая задача** - запускается 1 числа каждого месяца

### Запуск задач

Worker (обработчик задач)
```bash
celery -A config worker --loglevel=info
```

Beat (планировщик)
```bash
celery -A config beat --loglevel=info
```

Или вместе
```bash
celery -A config worker --beat --loglevel=info
```
