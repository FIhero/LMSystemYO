# Программа для онлайн обучения YO

## Функционал

### Модели:
- **Пользователи** - кастомная модель с email-авторизацией, телефон, город, аватар
- **Курсы** - название, описание, превью, владелец
- **Уроки** - название, описание, видео-ссылка, привязка к курсу
- **Платежи** - пользователь, дата оплаты, курс/урок, сумма, способ оплаты

### API Эндпоинты:

#### Курсы (`/api/courses/`)
- **GET** - список курсов (с количеством уроков и списком уроков)
- **POST** - создание курса
- **GET /api/courses/1/** - детали курса
- **PUT** - обновление курса  
- **DELETE** - удаление курса

#### Уроки
- **GET /api/lessons/** - список уроков
- **POST /api/lessons/create/** - создание урока
- **GET /api/lessons/1/** - детали урока
- **PUT /api/lessons/1/update/** - обновление урока
- **DELETE /api/lessons/1/delete/** - удаление урока

#### Пользователи
- **PUT /api/users/profile/update/** - редактирование профиля

#### Платежи (`/api/payments/`)
- **GET** - список платежей с фильтрацией:
  - `?paid_course=1` - фильтр по курсу
  - `?paid_lesson=1` - фильтр по уроку  
  - `?payment_method=cash` - фильтр по способу оплаты
  - `?ordering=payment_date` - сортировка по дате

### JWT Авторизация:
- Регистрация: POST /api/users/register/
- Получение токена: POST /api/users/token/
- Все эндпоинты закрыты авторизацией

### Права доступа:
- Создана группа 'moderators' 
- Модераторы могут редактировать любые курсы/уроки, но не могут удалять
- Обычные пользователи работают только со своими объектами
