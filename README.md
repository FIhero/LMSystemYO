# Программа для онлайн обучения YO

## Функционал
### Модели:
- **Пользователи** - кастомная модель с email-авторизацией
- **Курсы** - название, описание, превью, владелец
- **Уроки** - название, описание, видео-ссылка, привязка к курсу

### API Эндпоинты:
- **Курсы** (`/api/courses/`) - CRUD через ViewSet
- **Уроки** (`/api/lessons/`) - CRUD через Generic классы
- **Пользователи** (`/api/users/profile/update/`) - редактирование профиля
